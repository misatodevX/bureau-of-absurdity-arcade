# The Absurdity Arcade

One small arcade for two very different goose games:

- **Bureau of Absurdity** — an English-language survival game with an automatic donut cannon, five hostile departments, upgrades, and a cosmic HR toaster.
- **Goose: End of Bureaucracy** — a Russian-language survival game about sausage storms, bread-powered healing, and an overworked goose.

## Play

The arcade homepage is index.html. The two games live in games/bureau/ and games/goose/.

## Publish with GitHub Pages

The included GitHub Actions workflow deploys the repository root to GitHub Pages whenever a commit reaches main. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions** if it is not already selected.

Both games are static and run in the browser; there is no build step or server required.
